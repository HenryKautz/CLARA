\begin{minipage}{\textwidth}\small Each run is one problem, one pinned evidence file (the first N drives of a plan) and one recognize.sh \texttt{-{}-counter} method. CNF size is the instantiated problem plus evidence that every method starts from (max-term adds its own soft clauses); it depends on the problem and evidence, not the method. Times are wall-clock, 8 runs in parallel, each first limited to 1 minute and rerun with 15 minutes if it timed out (its time is then that of the rerun); every run finished. ``Top scorers'' are the hypotheses sharing the highest posterior, so a tie counts as among them but not as sole.\end{minipage}
